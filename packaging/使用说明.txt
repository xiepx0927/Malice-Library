# Malice-Library（Windows 版）

小说检索、在线阅读、CosersLove / 爱妹子 图集浏览、本地压缩包管理工具。

## 使用方法

1. 解压本压缩包到任意文件夹。
2. 双击 **启动.bat**。
   - 第一次运行会自动：创建虚拟环境 → 安装依赖 → 下载 Playwright Chromium（约 150MB，仅图集高级抓取需要，可跳过）。
   - 完成后自动打开浏览器进入 `http://127.0.0.1:5000`。
3. 以后每次双击 **启动.bat** 即可。

停止服务：关闭那个黑色命令行窗口。

## 版本与更新

- 版本号显示在页面 Logo 旁（v 开头，如 `v1.0.1`）。
- 点击顶栏「↻」按钮可**手动**检查 GitHub 上的最新版本（不会自动检查）。
- 发现新版本时弹窗提供两个选择：
  - **下载更新包**：访问 GitHub Release 页面，按需下载「完整包」或「增量更新包」，解压后覆盖旧文件即可。
  - **一键更新**：程序自动「下载 → 备份 → 替换 app.py / 前端模板」，完成后按提示重启窗口。
- 更新**绝不触碰** `archives/` 本地图库、`cos_cookie.json`；替换前自动备份，失败自动还原。
- 落后多个版本时建议使用「完整包」，老用户一版一步可优先使用「增量更新包」（仅含本次变更文件，更小更快）。

## 系统要求

- Windows 10 / 11（64 位）
- Python 3.10+
  - 未安装的话去 https://www.python.org/downloads/ 下载，安装时**务必勾选 "Add python.exe to PATH"**
  - 安装完若仍提示找不到 Python，注销/重启一次电脑

## 首次使用提示

- 首次进入「图集」页会自动通过 Cloudflare 验证（需要能正常访问 coserslove.com 的网络）。
- 「本地」标签用于查看压缩包图集，图片包存放在程序目录 `archives` 文件夹中（本包不附带任何内容）。

## 常见问题

| 现象 | 处理 |
| ---- | ---- |
| 提示 "不是内部或外部命令" | 之前版本 bat 编码问题；本包已修复为 ASCII+CRLF。若仍出现，请确认解压出的 `启动.bat` 在**本地磁盘**（不要在压缩包里直接双击，也避免放在 OneDrive/WPS 云同步盘） |
| 端口被占用 | 关掉占用 5000 端口的程序；或按下方说明改端口 |
| 图集打不开 | 检查能否用浏览器打开 https://coserslove.com ；等待几秒重试，服务会自动重新验证 |

## 自定义端口 / 局域网访问

编辑 `启动.bat` 末尾，在 `app.py` 前加一行环境变量即可：

```
set ALS_PORT=6000
set ALS_HOST=0.0.0.0
```

然后浏览器访问 `http://127.0.0.1:6000`（LAN 访问用 `http://本机IP:6000`）。

## 目录结构

```
Malice-Library/
├─ 启动.bat            一键启动（双击）
├─ app.py              主程序
├─ requirements.txt    依赖清单
├─ templates/index.html 前端页面
└─ archives/           存放本地图包（自动生成，可另行拷贝，更新不会覆盖）
```
